## 1. Overview

This document specifies the deterministic mathematical formulas, data constraints, normalization rules, and denominator criteria implemented in `server/src/services/reporting/metrics/`.

Under Companio's clinical safety architecture, large language models are strictly barred from computing or modifying numeric quantities. All numbers presented in clinical reports are generated by audited JavaScript functions.

## 2. Core Clinical Metrics

### 2.1 Medication Adherence (`medicationAdherence.js`)
*LOINC Code*: `59556-1` (Medication adherence)

$$\text{Adherence \%} = \text{round}\left(\frac{\text{Doses Taken}}{\text{Known Doses}}\times 100\right)$$

Where:
- $\text{Known Doses} = \text{Doses Taken} + \text{Doses Missed}$
- $\text{Expected Doses} = \text{Known Doses} + \text{Unknown Doses} + \text{Declined Doses}$

**Critical Invariant**:
- Unknown or declined responses are **never** coerced to missed or taken.
- If $\text{Known Doses} = 0$, the adherence rate is `null` and the calculation status is set to `INSUFFICIENT_DATA`. The system never fabricates a default 100%.

### 2.2 Sleep Duration & Quality (`sleepMetrics.js`)
*LOINC Code*: `93832-4` (Sleep duration), `93831-6` (Sleep quality)

$$\text{Sleep Avg} = \text{round}\left(\frac{\sum_{i=1}^{N_v} \text{hours}_i}{N_v}, 1\right)$$

Where $N_v$ is the count of **valid** sleep duration observations ($0 \le \text{hours}_i \le 24$).

**Critical Invariants**:
- Missing sleep observations are **never** counted as 0 hours.
- If no valid sleep observations exist, `sleepAvg` is `null` and the trend is marked `insufficient_data`.
- Split-half comparison ($\ge 4$ data points):
  - $\Delta \ge 0.5\text{ h} \rightarrow \text{improving}$
  - $\Delta \le -0.5\text{ h} \rightarrow \text{declining}$
  - Otherwise $\rightarrow \text{stable}$

### 2.3 Fluid Intake / Hydration (`hydrationMetrics.js`)
*LOINC Code*: `9052-2` (Oral fluid intake 24 hour)

$$\text{Hydration Avg (mL)} = \text{round}\left(\frac{\sum_{i=1}^{N_v} \text{mL}_i}{N_v}\right)$$

Where:
- Observations reported in glasses are normalized: $1\text{ glass} = 250\text{ mL}$.
- $N_v$ is the count of non-null, valid fluid intake measurements.
- Split-half comparison threshold is $200\text{ mL}$.

### 2.4 Physical Activity (`activityMetrics.js`)
*LOINC Code*: `89555-7` (Physical activity [Time] Per day)

$$\text{Activity Avg (min)} = \text{round}\left(\frac{\sum_{i=1}^{N_v} \text{minutes}_i}{N_v}\right)$$

- Split-half comparison threshold is $5\text{ minutes/day}$.
- Preserves self-reported activity categories (e.g. "walking", "gardening", "chair exercises").

### 2.5 Body Weight (`weightMetrics.js`)
*LOINC Code*: `29463-7` (Body weight)

$$\Delta \text{Weight} = \text{Weight}_{\text{latest}} - \text{Weight}_{\text{initial}}$$

- **Unit Safety**: Never calculates differences across incompatible units (e.g. comparing pounds to kilograms).
- Detects fluctuations $\ge 2.0\text{ lbs}$ (essential for monitoring fluid overload in congestive heart failure patients).

### 2.6 Symptom & Pain Tracking (`symptomMetrics.js`)
*LOINC Code*: `72514-3` (Pain severity - 0-10), `75325-1` (Symptom)

- Tracks frequency of occurrences, predominant severity (`mild`, `moderate`, `severe`), and first vs last reported timestamps.
- Explicitly links to contributing observation identifiers.

### 2.7 General Wellbeing (`wellbeingMetrics.js`)
*LOINC Code*: `71802-3` (General well-being score 1-10)

- Evaluates self-reported scores ($1–10$) and tracks social isolation / loneliness indicators.

## 3. Data Completeness & Limitations Audit (`dataCompleteness.js`)

For each reporting period of $D$ days, expected data points $E = D \times 4$ (medications, sleep, hydration, activity).

$$\text{Completeness Ratio} = \min\left(1.0, \frac{\text{Available Valid Data Points}}{E}\right)$$

- Overall status:
  - $\ge 0.85 \rightarrow \text{COMPLETE}$
  - $0.50 \le \text{ratio} < 0.85 \rightarrow \text{PARTIAL}$
  - $< 0.50 \rightarrow \text{INSUFFICIENT\_DATA}$
- Explicitly lists clinical limitations in report metadata and clinician displays.
