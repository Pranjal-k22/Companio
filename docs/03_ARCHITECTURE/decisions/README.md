## Adding a New ADR

1. Append a numbered entry (`ADR-0XX`) specifying **Status**, **Context**, **Decision**, **Verified Source Files**, and **Consequences / Trade-offs**.
2. Never retroactively erase superseded decisions; mark them `SUPERSEDED by ADR-0XX`.
