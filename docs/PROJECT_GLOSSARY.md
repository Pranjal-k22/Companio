# Companio Glossary

**Owner category:** Product and Engineering  
**Status:** Current terminology reference  
**Last verified:** 2026-11-12

| Term | Meaning |
|---|---|
| ABAC | Attribute-Based Access Control; authorization based on attributes and relationships |
| BAA | Business Associate Agreement; contract used where HIPAA business-associate requirements apply |
| BullMQ | Node.js job queue library using Redis |
| Caregiver grant | Patient-authorized, scope-limited access grant for a caregiver |
| Consent record | Auditable decision for a defined processing purpose |
| Deterministic safety net | Rule-driven evaluation of utterances against the configured concern taxonomy |
| EscalationEvent | Durable record of a clinical escalation/notification lifecycle |
| HMAC | Keyed-hash message authentication code, used for opaque references |
| IRB | Institutional Review Board or equivalent ethics review body, as applicable |
| LOINC | Logical Observation Identifiers Names and Codes |
| PHI | Protected Health Information under applicable HIPAA scope |
| Pseudonymization | Replacing identifiers with codes while re-identification may remain possible |
| RED flag | High-acuity safety category requiring configured escalation |
| Safe Harbor | A HIPAA de-identification method under 45 CFR §164.514(b)(2) |
| Tenant | Organization-scoped data and authorization boundary |
| YELLOW flag | Sub-acute concern category for monitoring or clinician review |
